# Quietzone — План реализации

> «QR codes that actually scan»
> Генератор QR-кодов, который не просто рисует картинку, а проверяет, прочитается
> ли код в реальных условиях: с логотипом в центре, в выбранных цветах, на
> выбранном размере печати и с выбранной дистанции — и учится на тестах
> сканирования вашего принтера.

---

## 0. Архитектурные решения

### 0.1 Полностью локальное приложение

Кодировщик QR написан с нуля в `src/lib/qr` (ISO/IEC 18004), никакой сторонней
QR-библиотеки и сети. Источник правды — `expo-sqlite`. Матрица кода нигде не
хранится: она детерминированно пересобирается из содержимого и уровня коррекции.

### 0.2 Разрешения

| Разрешение | Зачем |
|---|---|
| `VIBRATE` | Тактильный отклик (жест логотипа, чипы). |

Заблокированы в `app.json`: `INTERNET` (коды генерируются на устройстве),
`POST_NOTIFICATIONS`/`RECEIVE_BOOT_COMPLETED` (уведомлений нет, модуль удалён),
`CAMERA` (сканирования нет — тесты сканирования пользователь делает своей камерой
и отмечает результат), `READ_MEDIA_*` (экспорт идёт через системные диалоги
печати `expo-print` и шеринга `expo-sharing`), `SYSTEM_ALERT_WINDOW`.

### 0.3 Тема и шрифт

Только светлая тема. IBM Plex Mono для заголовков, чисел и технических подписей
(стиль чертежа), системный шрифт для текста.

## 1. Движок (`src/lib`) — цепочка, выход одного модуля вход другого

1. `qr/segments.ts` — **оптимальная разбивка** текста на режимы Numeric /
   Alphanumeric / Byte точным ДП по символам (цена в 1/6 бита, смена режима =
   заголовок, зависящий от класса версии).
2. `qr/gf.ts`, `qr/tables.ts` — поле GF(256), Рид — Соломон, таблицы всех 40
   версий × 4 уровня, зарезервированные "misdecode" слова малых версий.
3. `qr/encode.ts` — выбор минимальной версии, поток бит, блоки, чередование,
   функциональные узоры, зигзаг-раскладка, 8 масок со штрафом по четырём
   правилам (раздельно), **карта модулей**: для каждого модуля — тип узора или
   номер кодового слова и блока.
4. `damage.ts` — логотип в центре: закрытые модули → кодовые слова → блоки;
   нагрузка КАЖДОГО блока против его исправимой ёмкости, бюджет 60%,
   функциональные узоры под логотипом = сломан. `maxSafeLogo`.
5. `print.ts` — модуль в мм, контраст по WCAG, мин. размер под дистанцию.
6. `profile.ts` — **накапливаемая модель принтера**: байесовский гистограммный
   апостериор порога θ (мм модуля на 10 см), каждый тест сканирования
   домножает правдоподобие (логистика по ln(r/θ) с полом/потолком). Без тестов
   рекомендация = медиана (базовое правило), с тестами — 80-й перцентиль.
   Удаление теста — пересборка из априора и оставшихся тестов. Подсказка
   "самый информативный тест" — у медианы.
7. `advisor.ts` — проверки (содержимое, логотип, контраст, тихая зона, размер
   для дистанции) с цифрами; **варианты починки**, каждый проверен повторным
   прогоном всей цепочки, ранжированы "чинит → меньше усилий → дальше читается"
   (включая "уровень выше + логотип под его бюджет", "убрать логотип"); дифф
   what-if; "на сколько байт сократить, чтобы упасть на версию".
8. `content.ts` — WIFI:/MECARD:/mailto:/tel:/SMSTO: с экранированием.

Тесты: 19 (`qr.test.ts`, `engine.test.ts`), среди них сверка ёмкостей с таблицей
стандарта на 56 точках, учебные векторы HELLO WORLD, обратное чтение матрицы с
нулевыми синдромами Рида — Соломона, порядконезависимость апостериора.

**Проверено независимым декодером (jsQR) по скриншотам эмулятора**: ссылка и Wi-Fi
читаются; логотип 20%, для которого советчик пишет "15 из 13 исправимых — не
прочитается", jsQR действительно не читает; после "Shrink the logo to 12%" снова читает.

## 3. Экраны (6)

1. **Library** (`index`) — Grid Dashboard: сетка 2×N живых мини-кодов, первая
   ячейка "+" открывает шторку создания (тип, поля, пресеты "где будет код"),
   живой поиск, фильтр по типу, липкие заголовки Pinned / All, long-press меню.
2. **Studio** (`code/[id]`) — master-detail: вердикт, LogoSizer, проверки,
   варианты починки с Apply, инлайн-правка названия и содержимого, уровень
   коррекции (у каждого видна версия), цвета, логотип, тихая зона, цель печати.
3. **Anatomy** (`anatomy/[id]`) — "почему так": версия/ёмкость, сегменты против
   одного режима, карта модулей по блокам (тап по блоку), нагрузка блоков,
   8 масок со штрафами (тап — превью кода с этой маской).
4. **Print & test** (`print/[id]`) — печать в точных мм, шеринг PNG, what-if
   "сейчас / если" с диффом, профиль принтера (кривая апостериора, журнал
   тестов, свайп-удаление, шторка теста).
5. **Stats** — 7 секций, интерактивный донат по типам перестраивает экран.
6. **Settings** — значения по умолчанию, профили (переименование инлайн), сброс.

## 4. Собственные виджеты

QRView (код одним путём, проявление шторкой-сканером), LogoSizer (жестовый),
AnatomyMap + BlockLegend (тап), MaskBars (тап), SegmentStrip, PosteriorCurve,
PrintRuler, ChecksList, FixList.
